# ScreenTracker v1.0.0

The first public release of ScreenTracker!

## Features
- Application usage tracking
- Gaming activity tracking
- Productivity dashboard
- Monthly goals and task management
- Spotify music integration
- Usage history and statistics
- Minimal black-and-white interface

## Installation
1. Download `ScreenTracker-Setup.exe` from the Assets section below.
2. Run the installer.
3. Follow the installation instructions.
4. Launch ScreenTracker.

## Requirements
- Windows 10/11 (64-bit)
- Required .NET runtime, if not included in the installer.
